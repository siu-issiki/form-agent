## 独立レビュー指摘への対応

Medium: 改行された FAQ 内の「次のメッセージが表示された場合、受付済みです。」に続く受付例文が、新規の受付と誤判定された。同一行引用の負例ではこの形を検出できていなかった。

4 組それぞれで red を確認し、reader が候補の直前 160 文字から直前行の明示的な導入文（次/以下のメッセージ/文言が表示された場合、または表示例）を確認して、その候補だけを除外するよう修正した。一般的な FAQ の見出しだけでは除外しない。後方に実際の受付が加われば次の一致を採用するため、既存 FAQ が本物の受付を隠さない。確認画面の一括除外、対象 frame と request、新規表示の比較、failure パターンは変更していない。

追加 4 tests は 3 種類の導入文、FAQ のみ、新規の真受付、例示ではない FAQ リンクを検証する。旧 4 fail → 修正後 4 pass、受付系既存 10 tests も維持。

再検証: typecheck / lint / unit 655 件 / Worker 248 件が全成功。


再レビューで、同じ例示誤認がエラー文言でも確認段階の継続を妨げ得ると指摘されたため、例示除外を confirmation / failure 共通に適用した（追加コミット）。4 新規エラーは旧 4 fail → green。既存の「送信に失敗しました」も含めた 5 エラーで、例文のみは空・後方の実エラーは採用を確認。例示文末と一致位置の間の改行だけは無視する。failure パターンそのものや再送条件は変更していない。

最終再検証: typecheck / lint / unit 660 件 / Worker 248 件が全成功。

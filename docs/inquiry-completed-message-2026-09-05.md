# 単独のお問合せ完了文を受付結果として認識する

> 個別実装時点の記録です。統合時点の状態は[信頼性改善の検証記録](reliability-improvements-2026-09.md)を参照してください。

実サイトの2段階目の送信後証跡には「お問合せが完了いたしました。」だけが表示されていたが、結果はSUBMIT_CONFIRMATION_NOT_OBSERVEDだった。過去の結果は確定済みであり、結果変更・実先への再送はしない。受信先DBは未確認で、当時のDOM全文・表示時刻も保存されていない。

管理下の `ajax-inquiry-completed` は、POST応答を受けてフォームを取り除き、同じ単独文を表示する。2段階進行は実例の1回目SUBMIT_STAGE_PENDING→2回目submitおよび既存管理下で成立しているため、このケースは文言認識だけに絞る。

製品は既存の結果reader用正規表現へ、この完全な一文だけを行頭・行末境界付きで追加する。FAQ/表示例・否定・疑問・確認画面・送信前から同文言がある場合・要求未観測は成功にしない。既存のframe/POST観測・新規文言・再送防止条件は変更しない。

実readerを使う10テストは、旧実装で2 fail / 8 pass、修正後10 pass。旧失敗は通常の新規受付とFAQ後の本当の受付が未認識の2件。管理下の本番旧red→新greenは別途実施し、その結果を一般サイトの実績に加えない。
